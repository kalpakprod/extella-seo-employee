# Extella HR

Агент разбора откликов для HR: принимает пакет (вакансия + отклик/резюме/сопроводительное/ссылки),
возвращает проверяемую карточку кандидата — соответствие требованиям, сильные и слабые стороны,
красные/зелёные флаги, AI-чек, вопросы интервью и оценку 1–5 с указанием покрытия и ограничений.

Ключевой принцип: всё, что влияет на оценку, считает детерминированный слой кода. Порт модели
подготовлен для будущих объяснений, но пока не подключён к конвейеру; модель не меняет балл
и не принимает решений.

## Документация

- `docs/hr-agent-roadmap.md` — дорожная карта и исследование.
- `docs/hr-agent-spec.md` — спецификация реализованного MVP и публичного API.
- `docs/decisions/0001-hr-analysis-boundary.md` — граница анализа: что решает код, что модель,
  и осознанные отклонения (защищённые признаки, покрытие, ссылки, авторство текста).
- `prompts/hr-review.md` — инструкция модели для объяснений и вопросов интервью.

## Установка и проверки

```bash
npm install
npm run lint   # tsc --noEmit
npm test       # vitest run
```

## Использование

```ts
import { analyzeApplication } from './src/index.js';

const result = await analyzeApplication(request, { browser, extractor, extella });

if (result.status === 'completed') {
  console.log(result.report?.scorecard.overall);
}
```

Гарантии поведения:

- защищённые признаки (возраст, пол, национальность и др.) не влияют на оценку;
- отсутствие упоминания требования — это `unknown`, а не `missing`;
- каждое утверждение подкреплено цитатой из источника либо помечено как неизвестное;
- авторство текста (AI/человек) не устанавливается;
- ссылки читаются по SSRF-политике, логины и пароли агент не принимает;
- при неполном покрытии оценка не выводится (`overall = null`, `insufficientData = true`).

## Границы

Реализация покрывает этапы M0–M1 дорожной карты и частично M2–M3. Реальные интеграции Extella,
парсеры PDF/DOCX, UI и HR-workflow не реализованы — для них определены порты и заглушки
(`docs/hr-agent-spec.md`, раздел «Что не реализовано»).
