# Extella Universal SEO Employee 2.0

## Коротко

Extella Universal SEO Employee 2.0, это self-hosted рабочий контур для технических SEO-проверок. Он запускается через Docker Compose и объединяет бесплатное ядро CrawlSEO и SEOmator с детерминированными планами аудита, очередью запусков и локальным состоянием. Модель не устанавливает факты: Agent Zero получает только очищенные подтверждённые данные и формирует объяснение или рабочий план без инструментов.

Продукт предназначен для закрытого пилота, а не для публичного коммерческого запуска. Он не изменяет сайт и не выполняет рекомендации автоматически.

## Для кого

Первичный ICP пилота: SEO-агентства и независимые SEO-специалисты, которым нужен повторяемый технический аудит нескольких клиентских сайтов с отдельной историей, состоянием и очередью для каждой Цели. Это рабочая гипотеза для набора design partners, а не подтверждённый рыночный сегмент.

## Что подтверждено в продукте

- Пять детерминированных профилей: `service_b2b`, `ecommerce`, `local_business`, `content_media`, `saas_marketplace`.
- Для каждой Цели создаётся AuditPlan. Лимит обхода задаётся от 1 до 100 страниц, значение по умолчанию: 25.
- Несколько Целей работают с изолированными state, history, baseline и FIFO-очередью. Запуски доступны вручную и по ежедневному расписанию.
- CrawlSEO и SEOmator образуют бесплатный технический core. Google Search Console и DataForSEO остаются отдельными опциональными источниками: отсутствие их OAuth или credentials не блокирует технический аудит.
- При недоступности модели детерминированные находки и evidence сохраняются. Модельное объяснение не заменяет факт источника.
- Нет автоматической публикации, изменения сайта, outreach, покупки ссылок или другого исполнения рекомендаций.

## Текущий технический статус

На CT160 подтверждены preflight, маршрут `agy/gemini-3.7-flash-high`, полный API E2E `ready` на 25 страницах, обе source probes 25/25, пять browser samples, блокировка private targets, project-scoped backup/restore-check и релевантные тесты. Это подтверждает технический контур закрытого пилота. Это не подтверждает совместимость с любой моделью, работу через потребительскую подписку или BYOK, OAuth Google Search Console/DataForSEO, запуск на домене design partner, либо спрос, клиентов и выручку.

## Пилот

Запрос: 3-5 design partners из SEO-агентств и соло SEO. Для каждого согласованного сайта пилот фиксирует исходный процесс, выполняет audit, собирает решения пользователя и повторный запуск после ручного исправления.

Метрики пилота измеряются без заранее заданных целевых значений:

- time-to-report;
- доля принятых рекомендаций;
- повторное использование;
- стоимость запуска;
- ошибки и неполные запуски.

## Что нужно от design partners

Нужны согласованные сайты, право на аудит, контекст текущего процесса подготовки отчёта и обратная связь по рекомендациям. Партнёры не получают обещание роста трафика, позиций или выручки. Пилот проверяет, уменьшает ли детерминированный контур время до проверяемого SEO-отчёта и помогает ли принимать рекомендации.
